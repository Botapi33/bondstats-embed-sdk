Embedded Intelligence SDK · v1.1

Build fixed-income intelligence into your product.

One lightweight script gives websites, dashboards and research tools access to live BondStats components and a small JavaScript analytics API. Widgets render inside Shadow DOM, so host-page CSS cannot break them.

<script src="https://botapi33.github.io/bondstats-embed-sdk/embed.js" defer></script> <bondstats-system-pressure theme="dark"></bondstats-system-pressure>

Four components. One market layer.

The first release focuses on components that can live inside another product rather than sending the user away to a separate calculator.

Use the data in your own code.

The same script exposes a compact JavaScript API. That makes the SDK useful even when you do not want to render a BondStats component.

const pressure = await BondStats.getSystemPressure(); const spread = await BondStats.getSpread('Italy', 'Germany'); const us10y = await BondStats.getMarket('United States', '10Y');
